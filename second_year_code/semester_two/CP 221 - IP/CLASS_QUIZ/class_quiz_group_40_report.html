Topic: Difference between .html(), .text(), and .val()

Writing Part

In the Dynamic Table Manager page, the jQuery methods .html(), .text(), and .val() are all used to work with content, but each one serves a different purpose. The .html() method is used when we want to read or insert HTML markup inside an element. In the assignment solution, it updates the summary section below the table by placing a Bootstrap alert inside the #gradeOutput element. This is useful because the output contains formatted HTML such as <strong> tags and layout characters, not just plain text.

The .text() method is different because it works only with the visible text of an element. It ignores HTML tags and returns plain readable content. In the table manager, the grade for each student is read from the fourth table cell using code like $(this).find('td').eq(3).text(). This returns values such as 85, 72, or 91 as text before they are converted into numbers for calculations or sorting. The same method can also be used to collect student names or course titles from the table without bringing along any HTML markup.

The .val() method is specifically for form controls such as input boxes, select menus, and text areas. In this assignment, it is used to read the values entered by the user in the Name, Course, and Grade input fields before appending a new row to the table. For example, $nameInput.val() gets the student name, while $gradeInput.val('') clears the grade box after the new row has been added successfully. This makes .val() the correct method whenever the source of data is a form element rather than a normal paragraph, div, or table cell.

In summary, .html() is best for working with HTML structure, .text() is best for plain text content, and .val() is best for user-entered values in form elements. Together, these methods make the table manager interactive and allow the page to add rows, read table data, and display formatted output correctly.

Method Main Purpose Example from the Assignment
.html() Reads or writes HTML markup inside an element. $('#gradeOutput').html(...) inserts the summary alert below the table.
.text() Reads or writes plain visible text. $(this).find('td').eq(3).text() gets the grade from a table row.
.val() Reads or writes the value of a form control. $nameInput.val() and $gradeInput.val('') handle user input fields.
